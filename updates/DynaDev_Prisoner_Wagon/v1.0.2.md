## ⚙️ 2. Key Features & Config Additions (config.lua)

### 🎁 Reward System Toggles (Global & Per-Route)
You can now globally enable or disable monetary payouts, item rewards, or custom XP:
```lua
Config.EnableMoneyReward = true      -- true = Cash/Bank payouts enabled | false = disabled
Config.EnableItemReward = true       -- true = Items rewarded | false = disabled
Config.EnableCustomXPReward = true   -- true = Custom XP & server_custom.lua hooks enabled | false = disabled
```

### 📦 Configurable Route Rewards & XP
Each route can have its own reward configuration:
```lua
enableMoney     = true,              -- Enable/disable money payout for this route
payout          = 50,                -- Payout amount
rewardType      = "cash",            -- "cash" or "bank"

enableItems     = true,              -- Enable/disable item rewards for this route
items           = {
    { name = "bread", amount = 2 },
    { name = "water", amount = 2 },
    { name = "bandage", amount = 1 },
    { name = "lockpick", amount = 1 },
},

xpAmount        = 50,                -- Custom XP awarded upon completion
```

### 🌐 Discord Webhook Logging
Rich embed logs for Mission Accepted, Completed, and Failed (including Officer Info, Payout, and Items Awarded):
```lua
Config.DiscordWebhook = "YOUR_DISCORD_WEBHOOK_URL"
```

### 🎯 Target & Prompt Settings
```lua
Config.Target = {
    useOxTarget = true,    -- true = use ox_target | false = use native prompts [E]/[R]/[G]
    distance = 2.5
}
```

### 👮 Law Job Lock
```lua
Config.JobLock = true      -- true = Only law enforcement | false = All players
Config.LawJobs = {
    'marshal',
    'vallaw',
    'rholaw',
    'blklaw',
    'strlaw',
    'stdenlaw',
    'armlaw',
    'tumlaw'
}
```

## 🔌 3. Custom Server Hooks (`server/server_custom.lua`)
Open (unescrowed) file to add your custom server-side events, XP, or external logs:
* `prisoner_wagon:server:onMissionStarted(source, missionId, routeData)`
* `prisoner_wagon:server:onMissionCompleted(source, missionId, payout, routeData)`
* `prisoner_wagon:server:onMissionFailed(source, missionId, reason)`

---

## 📦 4. Server CFG Setup
Ensure resources start in the following order in your `server.cfg`:

```cfg
ensure ox_lib
ensure DynaDev_libs
ensure DynaDev_Prisoner_Wagon
```

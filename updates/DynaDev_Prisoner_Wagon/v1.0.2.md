# DynaDev Prisoner Wagon - VORP & RSG Conversion Guide (v1.0.2)

This update refactors the script to be fully standalone and compatible with both **RSG** and **VORP** using the new **DynaDev_libs** dependency.

---

## 📋 1. Manifest Changes (fxmanifest.lua)
Replace your `fxmanifest.lua` content with the following:

```lua
fx_version 'cerulean'
game 'rdr3'
rdr3_warning 'I acknowledge that this is a prerelease build of RedM, and I am aware my resources *will* become incompatible once RedM ships.'
lua54 'yes'

author 'DynaDev'
description 'Prisoner Wagon Inmate Transfer for Law Enforcement'
version '1.0.2'

shared_scripts {
    '@ox_lib/init.lua',
    'config.lua',
}

client_scripts {
    '@DynaDev_libs/client/main.lua',
    'client/client_main.lua',
    'client/npcs.lua'
}

server_scripts {
    '@DynaDev_libs/server/main.lua',
    'server/server_main.lua',
    'server/server_versionchecker.lua'
}

dependencies {
    'DynaDev_libs',
    'ox_lib',
}

ui_page 'html/index.html'

files {
    'locales/*.json',
    'html/index.html',
    'html/styles.css',
    'html/app.js',
}
```

---

## ⚙️ 2. Config Settings (config.lua)
Ensure you have the following target configuration in your `config.lua`:

```lua
Config.Target = {
    useOxTarget = true,    -- true = use ox_target | false = use native circle prompts [E]/[R]/[G]
    distance = 2.5
}
```

---

## 📦 3. Server CFG Setup
Ensure you start the resources in this exact order in your `server.cfg`:

```cfg
ensure DynaDev_libs
ensure DynaDev_Prisoner_Wagon
```

---

## 🎯 4. Target System Requirements (ox_target)
- If you set `Config.Target.useOxTarget = true` in your `config.lua`, ensure you have **ox_target** started in your `server.cfg` (usually before the script).
- If you set `Config.Target.useOxTarget = false`, **ox_target is NOT required** and the script will run entirely using native prompts, allowing you to run the resource without having ox_target installed on your server.

# DynaDev Shared Framework Compatibility Library - v1.0.1

This update introduces major enhancements to **DynaDev_libs** including VORP weapon spawning support, dynamic roleplay character name retrieval for notifications/logs, and severe server-side stability improvements.

---

## 📋 1. Manifest Changes (fxmanifest.lua)
Replace your `fxmanifest.lua` content with the following:

```lua
fx_version 'adamant'
games { 'rdr3' }
rdr3_warning 'I acknowledge that this is a prerelease build of RedM, and I am aware my resources *will* become incompatible once RedM ships.'
lua54 'yes'

author 'DynaDev'
description 'DynaDev Shared Library for Framework Compatibility'
version '1.0.1'

shared_scripts {
    'config.lua'
}

client_scripts {
    'client/main.lua'
}

server_scripts {
    'server/main.lua',
    'server/server_versionchecker.lua'
}
```

---

## 🚀 2. What's New in v1.0.1
* **VORP Weapons Integration:** Intercepts `WEAPON_` item hashes and automatically handles them via VORP's native weapon spawning API (`createWeapon`) instead of general inventory imports.
* **Roleplay Character Names:** Implemented `Bridge.GetCharacterName(source)` to return the character's RP first and last name for both VORP and RSG frameworks.
* **Crash Protection:** Added safety wrappers (`pcall` and nil checks) for database queries and framework objects during server startup to prevent server-side crashes.

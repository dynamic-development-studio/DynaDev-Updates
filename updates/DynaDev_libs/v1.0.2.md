# 📚 DynaDev_libs - Update Guide (v1.0.2)

A universal RedM bridge and utility library providing multi-framework compatibility between **RSG-Core** and **VORP Framework**.

---

## 📋 1. Manifest Structure (fxmanifest.lua)

```lua
fx_version 'adamant'
games { 'rdr3' }
rdr3_warning 'I acknowledge that this is a prerelease build of RedM, and I am aware my resources *will* become incompatible once RedM ships.'
lua54 'yes'

author 'DynaDev'
description 'DynaDev Shared Library for Framework Compatibility'
version '1.0.2'

shared_scripts {
    'config.lua'
}

client_scripts {
    'client/main.lua'
}

server_scripts {
    'server/main.lua',
    'server/server_versionchecker.lua'
}

escrow_ignore {
    'config.lua'
}
```

---

## 🌟 2. What's New in v1.0.2

* **Unified Multi-Framework Bridge:** Full dynamic support for RSG-Core and VORP Core framework operations.
* **Universal Player & Ledger Functions:** Seamless handling for player identity, jobs, and cash/bank money transactions.
* **Smart Inventory Dispatcher:** Automatic item and weapon management for both `vorp_inventory` and `rsg-inventory`.
* **Multi-Notification System:** Support for `DynaDev_notify`, `mega_notifications`, `ox_lib`, and native framework alerts.
* **Real-Time Job Sync & Caching:** Instant synchronization with framework job change events.
* **Silent Production Mode:** Clean console output with all debug messages hidden when debug mode is disabled.

---

## ⚙️ 3. Configuration (config.lua)
Configure your notification preferences and language directly in `config.lua`:

```lua
Config.NotificationType = 'DynaDev_notify'      -- 'DynaDev_notify' | 'mega_notifications' | 'ox_lib' | 'framework'
Config.NotificationLanguage = 'en'              -- 'en' or 'el'
Config.Debug = false
```

---

## 📦 4. Server CFG Setup
Ensure resources start in the following order in your `server.cfg`:

```cfg
ensure ox_lib
ensure DynaDev_libs
ensure DynaDev_Prisoner_Wagon
```

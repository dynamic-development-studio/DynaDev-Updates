# 📚 DynaDev_libs - Update Guide (v1.0.2)

A universal RedM bridge and utility library providing multi-framework compatibility between **RSG-Core** and **VORP Framework**.

---

## 📋 1. Manifest Structure (fxmanifest.lua)

```lua
fx_version 'adamant'
games { 'rdr3' }
rdr3_warning 'I acknowledge that this is a prerelease build of RedM, and I am aware my resources *will* become incompatible once RedM ships.'
lua54 'yes'

author 'DynaDev'
description 'DynaDev Shared Library for Framework Compatibility'
version '1.0.2'

shared_scripts {
    'config.lua'
}

client_scripts {
    'client/main.lua'
}

server_scripts {
    'server/main.lua',
    'server/server_versionchecker.lua'
}
```

---

## 🌟 2. What's New in v1.0.2

### 👮 Unified `Bridge.GetPlayer(source)`
Provides a uniform player object across both VORP and RSG:
```lua
local Player = Bridge.GetPlayer(source)
if Player then
    local citizenId = Player.PlayerData.citizenid
    local fullName  = Player.PlayerData.charinfo.firstname .. " " .. Player.PlayerData.charinfo.lastname
    local jobName   = Player.PlayerData.job.name
    local jobLabel  = Player.PlayerData.job.label

    -- Add/Remove money seamlessly
    Player.Functions.AddMoney('cash', 100, 'reason') -- Works on VORP (currency 0) & RSG
    Player.Functions.AddMoney('bank', 500, 'reason') -- Works on VORP (currency 2) & RSG
    Player.Functions.RemoveMoney('cash', 50)
    local cash = Player.Functions.GetMoney('cash')
end
```

### 📦 Smart Inventory Routing (`Bridge.AddItem`)
* Automatic weapon detection (calls `vorp_inventory:createWeapon` if the item is a weapon).
* Automatic normal item insertion (`vorp_inventory:addItem` on VORP, `rsg-inventory:AddItem` on RSG).

### 🔔 Multi-Notification Dispatcher (`Bridge.Notify`)
Configure your preferred notification system in `config.lua`:
* `Config.NotificationType = 'DynaDev_notify'` *(HTML NUI)*
* `Config.NotificationType = 'mega_notifications'`
* `Config.NotificationType = 'ox_lib'`
* `Config.NotificationType = 'framework'` *(VORP TipRight / RSG Notify)*

### 🔄 Real-Time Job Sync & Cache
* Real-time listener for `vorp:SelectedCharacter`, `vorp:setJob`, `RSGCore:Client:OnPlayerLoaded`, and `RSGCore:Client:OnJobUpdate`.
* Fast client-side job retrieval via `Bridge.GetPlayerJob()`.

### 🔇 Silent Production Mode
* Auto-detection and spawn logs silenced behind `Config.Debug = false` for a clean server console.

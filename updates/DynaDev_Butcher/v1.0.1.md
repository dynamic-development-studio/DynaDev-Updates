# DynaDev Butcher - VORP & RSG Conversion Guide (v1.0.1)

This update refactors the script to be fully standalone and compatible with both **RSG** and **VORP** using the new **DynaDev_libs** dependency.

---

## 📋 1. Manifest Changes (fxmanifest.lua)
Replace your `fxmanifest.lua` content with the following:

```lua
fx_version 'cerulean'
game 'rdr3'
lua54 'yes'

author 'DynaDev'
description '👨🏻‍🍳🥩 DynaDev Butcher | Ultimate Butcher Experience'
version '1.0.1'

dependencies {
    'ox_lib',
    'DynaDev_libs',
}

shared_scripts {
    '@ox_lib/init.lua',
    'config.lua',
}

client_scripts {
    '@DynaDev_libs/client/main.lua',
    'client/dataview.lua',
    'client/client_main.lua',
    'client/npcs.lua',
}

server_scripts {
    '@DynaDev_libs/server/main.lua',
    'server/server_main.lua',
    'server/server_versionchecker.lua'
}

ui_page 'nui/index.html'

files {
    'locales/*.json',
    'nui/index.html',
    'nui/style.css',
    'nui/script.js',
    'nui/carcass_carrying.png'
}
```

---

## ⚙️ 2. Config Additions (config.lua)
Make sure you have the following options under your general config settings:

```lua
Config.UseTarget = false    -- true = ox_target | false = proximity key (works on VORP too)
Config.ActionKey = 'G'      -- Key used for interaction (e.g. 'G', 'E', 'J')
```

---

## 📦 3. Server CFG Setup
Ensure you start the resources in this exact order in your `server.cfg`:

```cfg
ensure DynaDev_libs
ensure DynaDev_Butcher
```

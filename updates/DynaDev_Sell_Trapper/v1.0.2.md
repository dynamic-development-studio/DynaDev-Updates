# DynaDev Sell Trapper - VORP & RSG Conversion Guide (v1.0.2)

This update refactors the Sell Trapper script to use the centralized **DynaDev_libs** for complete VORP and RSG cross-framework support.

---

## 📋 1. Manifest Changes (fxmanifest.lua)
Replace your `fxmanifest.lua` content with the following:

```lua
fx_version 'cerulean'
game 'rdr3'
lua54 'yes'

author 'DynaDev'
description '🔪🤝 DynaDev Sell Trapper | The most efficient Sell Trapper for RedM!'
version '1.1.0'

dependencies {
    'ox_lib',
    'DynaDev_libs',
}

shared_scripts {
    '@ox_lib/init.lua',
    'shared/config.lua',
    'shared/items.lua'
}

client_scripts {
    '@DynaDev_libs/client/main.lua',
    'client/client_main.lua',
    'client/npcs.lua'
}

server_scripts {
    '@DynaDev_libs/server/main.lua',
    'server/server_main.lua',
    'server/server_versionchecker.lua'
}

ui_page 'nui/index.html'

files {
    'locales/*.json',
    'nui/index.html',
    'nui/style.css',
    'nui/script.js'
}
```

---

## ⚙️ 2. Config Additions (shared/config.lua)
Ensure these options are set under your interaction configuration:

```lua
Config.UseTarget = false    -- true = ox_target | false = proximity key (works on VORP too)
Config.ActionKey = 'J'      -- Key used for interaction (e.g. 'J', 'E', 'G')
```

---

## 📦 3. Server CFG Setup
Make sure they are loaded in this order in your `server.cfg`:

```cfg
ensure DynaDev_libs
ensure DynaDev_Sell_Trapper
```

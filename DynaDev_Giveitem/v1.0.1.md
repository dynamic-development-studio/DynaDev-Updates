# DynaDev Give Item - VORP & RSG Conversion Guide (v1.0.1)

This update refactors the Give Item Admin Menu to support both **RSG** and **VORP** frameworks using the centralized **DynaDev_libs** bridging dependency.

---

## 📋 1. Manifest Changes (fxmanifest.lua)
Replace your `fxmanifest.lua` content with the following:

```lua
fx_version 'cerulean'
game 'rdr3'
lua54 'yes'

author 'DynaDev'
description '🔰 DynaDev Give/Spawn Item UI — RSG/VORP inventory browser for admins'
version '1.0.1'

ui_page 'html/index.html'

dependencies {
  'ox_lib',
  'DynaDev_libs',
}

shared_scripts {
  'config.lua'
}

client_scripts {
  '@DynaDev_libs/client/main.lua',
  'client/client_main.lua'
}

server_scripts {
  '@DynaDev_libs/server/main.lua',
  'server/server_main.lua',
  'server/server_versionchecker.lua'
}

files {
    'html/index.html',
    'html/style.css',
    'html/app.js',
    'html/images/placeholder.svg',
    'locales/*.json',
}

escrow_ignore {
    'config.lua',
    'locales/*.json',
}
```

---

## ⚙️ 2. Permissions Configuration
To allow admin staff to open and use the menu on VORP or RSG, you have two options:

### Option A: ACE Permissions (Recommended)
Add the following line to your `server.cfg` or `permissions.cfg`:
```cfg
add_ace group.admin dynadev.giveitem.use allow
```

### Option B: VORP In-Game Group
Assign your target admin player to the `admin` group:
```text
/addGroup [player_id] admin
```

---

## 📦 3. Server CFG Setup
Ensure resources load in this order in your `server.cfg`:

```cfg
ensure ox_lib
ensure DynaDev_libs
ensure DynaDev_Giveitem
```

## 💡 4. Troubleshooting & Item Icons

If some items or weapons in the menu display a folder icon instead of their actual image:
1. This indicates that **there is no `.png` image file** for that specific item inside your active inventory resource's image folder:
   - **VORP Core:** `vorp_inventory/html/img/items/`
   - **RSG Core:** `rsg-inventory/html/images/`
2. **How to fix:** 
   - Find or create a `.png` image for the missing item.
   - Rename the file to match the item's database ID **exactly in lowercase** (e.g., if the ID is `1789_PENNY`, name it `1789_penny.png`; if it is `WEAPON_REVOLVER_NAVY`, name it `weapon_revolver_navy.png`).
   - Place the `.png` file in your inventory's items image directory.
   - Restart the inventory resource or the server, and the image will load automatically!
